# Validation Quickstart

Use the repository's isolated PostgreSQL fixture; do not target the running user database.
Run focused HTTP, demo workflow and Chat security tests first, then the complete required
Quality workflow on the final PR head. Check authenticated tools/list choices, a fresh
Playground reservation's retained review before approval, copied confirmation arguments,
separate callable reconciliation guidance, stale refusal and replay. Both provider tests
must show zero proposals under the exact published read-first instruction and retained
shipment evidence even when consignment objects are absent. Regenerate catalogs with
`make docs-generate` and verify `make docs-catalog-check`.
