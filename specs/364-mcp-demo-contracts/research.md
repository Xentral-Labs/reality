# Research

- Decision: preserve the executable MCP schema after SDK tool registration. Rationale:
  `_annotation` converts primitive enums to plain strings; nested/union preservation
  already has an authoritative schema override. Keep typed call signatures. Reject
  replacing the whole typed handler with unvalidated dictionaries.
- Decision: retain the existing shared state-bound review for fresh Playground
  reservations. Rationale: the current blanket `purpose != playground` shortcut creates
  a generic proposal; confirmation then upgrades it. Preserve lesson/admission contracts
  rather than globally changing every Playground operation without evidence.
- Decision: provide exact handoff arguments and separate callable response guidance.
  Rationale: legacy preparation is a real state transition, and receipts are recorded
  evidence, not a mutable vocabulary cache. Do not rewrite historical receipts.
- Decision: enforce explicit current-turn read-first through existing access dispatch
  in both providers and give shipping turns bounded retained movement context. Rationale:
  model instructions alone allowed a timezone proposal and a false global shipping
  claim. Reuse canonical reads; no new shipping total, authority or domain rule.
- No unresolved technology or product question requires delegated research.
