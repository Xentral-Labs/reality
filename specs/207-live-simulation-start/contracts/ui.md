# Interface contract

Existing Demo Data status GET and control POST schemas remain unchanged. Status read accepts browser cancellation. A successful running/non-error status permits the header link; absence, unauthorized, loading, failure or non-running hides it. Link selects route demo-data in the same tenant. Pulse is decorative, reduced motion disables it, accessible name is the existing localized Live simulation string. Header visibility asserts configured simulation state, not infrastructure health.

Internal create_schedule optionally accepts bounded initial_offsets_seconds. It is not exposed as a CLI/MCP option. Existing callers and schedules retain ordinary first-interval timing.
