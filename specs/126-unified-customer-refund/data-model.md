# Data model
No DDL or migration. Existing credit_note Document owns received amount, not settlement status. customer_refund Document records stated refund amount/reference/date and optional SourceRecord. Its posting group contains AR debit and cash credit. SettlementAllocation links refund AR debit to credit AR credit using existing opaque ledger IDs. Active allocations on either side consume credit capacity; ledger reversals deactivate associated allocations at read time. ChangeProposal stores reviewed intent; existing business events carry action attribution and historical evidence.
