# Contracts
sales_credit_record legacy order_line_id/quantity/gross_amount/number/effective_at remains unchanged. New mutually exclusive shape: invoice_id, lines:[{invoice_line_id,quantity,gross_amount}], gross_amount, number, reason, allocation_amount (explicit, zero allowed), optional effective_at. New receipt uses existing records list families: source_record, document, document_line(s), ledger_entry(two), optional settlement_allocation. Shared preparation/review/confirmation uses existing delivery-action endpoints. GET invoice-credit context is read-only, tenant scoped and returns server-derived credit capacity/evidence and open amount. MCP exposes the new shape through the existing sales_credit_record_propose identity.
