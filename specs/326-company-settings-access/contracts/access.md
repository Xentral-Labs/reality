# Settings and Access Contract
GET company settings/ai remains owner-only and returns the existing metadata shape without raw secrets. MCP display validates its own origin; runtime OAuth discovery uses explicit MCP_AUTHORIZATION_ISSUER or API_URL and retains HTTPS validation in production.
Private report list without active membership returns the existing structured AnalyticsError envelope with code company_membership_required; it includes no report identifiers or counts. Detail and change remain generic NotFound for unauthorized authors. Active members and owners retain their existing private scope.
Company cards label missing membership explicitly and expose no owner actions. The private library translates membership refusal in all supported languages and preserves retry behavior.
