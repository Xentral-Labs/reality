# Navigation contract

`/tool-usage/#model:commitment` and `/de/tool-usage/#model:commitment` select the same object in the respective language. `#model:` opens the overview. Selecting related covered objects pushes history. Action links open existing Tool Usage manuals; Back restores model context. Unknown model keys show the overview. Search matches keys, names, purposes and field names/meanings. Field text wraps; technical defaults appear in expandable field details on narrow screens.
