# Research: Web and MCP Proposal Review Parity

The MCP catalog exposes 102 proposal-producing definitions. Web has recoverable routing for 23
application-tool types. Nine additional types already satisfy specialized delivery-review
eligibility but are omitted from Chat and Decisions routing. Seventy remaining types have no
generic Web recovery even when a separate manually initiated Web workflow exists.

Use one server classification per stored proposal. Preserve specialized cards and add one common
fallback that displays stored intent and uses the original approval service. Derive coverage from
the registries; do not maintain a copied audit spreadsheet or new demo-only tools.
