# Native reference lookup contract

`shopify_source_reference_lookup` is a normal read tool. Use the exact frozen
four-field retained source binding and family `company`, `location` or `item`.
`query` defaults to an empty bounded listing. An explicit `record_id` overrides
text filtering. At most 20 qualified records are returned; `hasMore` reflects a
bounded 21st matching record, never complete tenant inventory or upstream data.

`input.schema.json` is the strict native DTO. `actual-sdk-advertisement.json` is
captured through authenticated MCP tools/list, including the actual transformed
inputSchema and readOnly/non-destructive annotations. The initialize receipt
proves 2025-03-26 negotiation. The source/entity IDs in the examples are synthetic.
No token or signing proof is stored. Exact existing role/digest/unit observations
are context, not approval or quantity-conversion authority. Ambiguity is preserved.

Only the current native runtime is supported. This packet neither deploys an
old99 overlay nor broadens an existing token or Tuesday connection grant.

Freshness is a bounded optimistic current read, not a serializable snapshot or
final-effect authorization. The service rechecks its bounded selected evidence;
changes after that boundary remain possible. Native392 must independently lock
and revalidate current source, references, credit and authority before mutation.
