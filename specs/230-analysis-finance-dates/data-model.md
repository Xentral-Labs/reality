# Read-time model

No table, column, migration or write is added. Property.temporal optionally declares
calendar semantics for lossless text. Node.derivation is an allowlisted finance.aging
identifier restricted to document identity. The adapter joins canonical per-document
aging rows as a bound JSONB recordset with numeric/date/integer/text columns; it is
never stored. Customer/supplier nodes scope existing invoice and opening-debt types.
Measures preserve currency and snapshot additivity. Existing model keys stay stable.
