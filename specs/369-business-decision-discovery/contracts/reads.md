# Existing discovery contract extension
`business_records_discover` / application `business_discover` accepts family `executed_decision`. Optional `document_id` is an opaque retained sales/purchase order ID. Query searches tool type; exact record_id takes precedence. Only status executed is selected. Order association requires a retained event with action_id and exact document, line, commitment, reservation or movement subject membership.
Records carry opaque id/proposal_id, tool, status, created_at/decided_at, review_read=proposal_review and verification_read=proposal_execution_status. association_scope=retained_execution_events; absence does not prove full history. Metadata decision_coverage explains the selected event association boundary. Raw input/output and approval tokens are omitted. Without an order filter, company-scoped executed metadata is listed without claiming a specific order association (association_scope=retained_executed_decisions).
Page/legacy shapes, limit 1–100, cursor scope, no-write metadata and existing tool permissions remain. Foreign exact order/Decision behaves as not found; non-order document scope is refused. Existing document_line scope and other-family refusals remain. Exact follow-up tools accept discovered proposal_id and enforce their existing policy independently.
