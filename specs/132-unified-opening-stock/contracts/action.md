# Action contract
Common delivery-actions prepare uses tool=movement_create, arguments={movement_type:opening_stock,item_id,to_location_id,quantity,occurred_at?}, request_id. Existing review/confirm/detail/reconcile routes apply. Detail adds movement_type=opening_stock to choose the standalone UI, review state/effect, canonical movement receipt and optional current-stock observation. Source/tracking/commitment/from/reason fields are outside this bounded review. Legacy raw CLI/MCP approval semantics remain compatible; new reviewed proposals require matching token and explicit confirmation.
