# Review Contract

proposal_review accepts optional principal, default None. Private carriers are omitted from
common input for every caller. private_review.state is readable, hidden or unavailable;
details are present only for readable. Nonauthor private preview/receipt are withheld.
Web forwards authenticated identity; other existing callers remain anonymous unless explicit.

Normal scoped dialog view shows labeled business values. Technical JSON is in closed details
and omits credentials and private carriers, including on legacy response fallback.
Shipment execution still sends the exact current review token separately from presentation.
