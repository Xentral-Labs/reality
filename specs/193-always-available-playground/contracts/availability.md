# Availability Contract

Storyline library `enabled`, Playground runs `entry_enabled`, company setup
`practice_enabled` and free entry `enabled` remain booleans and return true after
existing read admission. Setup environments include Sandbox; business remains
restricted to active accounts. Mutating entry retains explicit confirmation,
owner/admission/quota/archive checks and request replay. The retired variable has
no effect even when false, empty or malformed. No endpoint/schema is added.
