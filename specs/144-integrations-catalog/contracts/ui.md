# UI contract

Integrations retains its route and systems/records/documents URL values. Only systems and records are primary navigation tabs; documents remains a contextual register. Systems is labelled My integrations. Add integration opens catalog, then instance naming, data choices and review. Save draft writes only session storage. Existing source controls remain distinct and still call shared services. CSV uses the existing import dialog. Close/Escape cancels unsaved edits. No provider network traffic or credentials.

Received records open shared Inspector details with actual supported source-FK links and recorded event paths to subjects. Results are tenant-scoped and limited to 100 per family, with truncation indicated. The original payload remains lossless.
