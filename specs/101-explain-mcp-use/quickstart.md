# Quickstart: Verify MCP Customer Guidance

1. Run `npm run test:contracts` and `npm run build` in `provider-site`.
2. Run `npm test` and `npm run build` in `apps/docs` using the scripts declared by that package.
3. Open the landing page and confirm the compact MCP bridge is readable at desktop and mobile widths, follows the agent-context example, and contains no capability-card grid.
4. Follow the guide link and confirm English and German routes contain the same setup and safety boundaries.
5. Confirm no page claims OAuth, automatic refresh tokens, certification, or one-click client support.

Expected: a first-time reader can identify MCP as the connection path, understand governance, reach the concrete jobs and setup instructions, and configure the implemented generic HTTPS/bearer contract.
