# Disposable read models
Order row: tenant, generation, opaque document identity, received sort timestamp, next transition timestamp, flags, exact display payload and additive contribution payload. Composite tenant/generation/document primary key. Cohort paging indexes include tenant/generation/flag/received/document; transition index includes tenant/generation/next transition/document.
Mail row: tenant, generation, source identity, received timestamp, direction, waiting/unread evidence and display payload. Composite tenant/generation/source primary key; indexed cohort ordering. Original/reply payloads preserve exact source identity; unknown completion is null.
Summary: existing projection row under `business_performance`, includes active generation, counters, ancillary observations and durable rebuild/event traversal state. Existing checkpoint records processed sequence and next clock transition; partial work never advances beyond completed coverage. No FK from Reality to caches; cache generation IDs are internal only.
