# Preview read contract

Existing GET Inspector route accepts optional `preview=true` (default false). Supported kinds add `preview_sections`: ordered `{title, rows, has_more?}` sections. Rows retain existing `{label,value,display_parts?,link?,tone?}` contract and optional `hint` for current master-data fallback, `original_label` to protect business labels and `translate_value` for controlled status/direction vocabulary. Original values are not translated. Lists contain at most 20 rows per section; `has_more` announces additional records available in the full explanation. Unsupported kinds retain existing compact behavior. Full Inspector requests and sections are unchanged. No writes, new routes or application tool schemas.

Master-data register rows add transient business display fields (accounting/payment-term code and currency, item type/default-location name, or location type/parent name/stock eligibility). Detail reads additionally return the same `preview_sections` contract. Existing raw editable fields and the snapshot-based `expected_revision` remain unchanged. Labels are resolved in tenant-scoped batches bounded to the selected page; no new identifiers or stored values are introduced.
