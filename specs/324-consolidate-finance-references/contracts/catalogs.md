# Catalog Contracts

All existing commands, services, response fields, resource names and errors are unchanged. Internal references are not local posting accounts; external references remain target-owned.

The two original SQL names support catalog INSERT, UPDATE, DELETE and RETURNING using their original column sets. Family-crossing writes are refused. Existing service immutability and confirmation remain authoritative. Incoming FKs are physical and preserve tenant/kind/target validation.

Inspection distinguishes two logical views from one physical table. Company deletion and physical row counts process the store once.
