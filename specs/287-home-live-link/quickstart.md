# Quickstart: Home Live Link Placement

1. Run `node --test apps/web/scripts/home-live-link-contract.test.mjs`.
2. Run `npm --prefix apps/web run build`.
3. Run `npm --prefix apps/web run i18n:audit` and `npm --prefix apps/web run format:check`.
4. Open Welcome as a company owner on desktop and at 390 pixels wide.
5. Confirm the localized action is beside the Live status, the period selector is separate on the right, focus is visible, activation opens the existing live monitor and the page does not overflow horizontally.
