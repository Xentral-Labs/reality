# Research

Spec Kit planning research was delegated read-only to spectator_research.

- Decision: standard-library loopback server and static assets. Rationale: independent spectator needs no database/product shell/npm dependency. Alternatives: React in apps/web would violate separate scope; static exported HTML alone cannot observe growing runs.
- Decision: resolve message party from source_record_ingest context matched to accepted source receipt, never generic sender. Party names from exact party_create inputs and returned IDs. Legacy final reports retain order references and world events.
- Decision: publish atomic spectator.json after checkpoints, with released world observations only. Existing world.json is terminal-only. Preparing a business proposal does not send/approve email. Keep action and message states separate.
- Decision: tolerate incomplete final JSONL line with notice, reject path and symlink escapes, render text through textContent. Report absence is unfinished, not process liveness.
- Decision: use installed Chromium and Playwright for real browser validation. No infrastructure/provider configuration needed.
