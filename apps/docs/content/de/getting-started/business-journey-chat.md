# Reality fragen

Frage, ob Reality eine Geschäftssituation unterstützt. Antworten basieren auf dem veröffentlichten
[Business Journey Guide](./business-journeys), nennen die passenden Journey-IDs sowie Nachweisgrad
und Grenzen. Dieser öffentliche Assistent ist read-only: Er sieht keine Unternehmensdaten und führt
keine Tools aus.

Für unternehmensbezogene operative Fragen nutze den normalen Reality Chat. Um ein fehlendes Szenario
vorzuschlagen oder für Vorschläge zu stimmen,
<a href="__APP_URL__/?route=settings&settingsView=personal#journey-suggestions">öffne Reality</a>.
